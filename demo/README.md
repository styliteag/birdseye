# birdseye demo — local NetBird for tests and screenshots

A self-contained NetBird with a fictional
company "Acme", modelled on the prod compose (Traefik in front of
`netbird-server` + `dashboard`, `birdseye` + `birdseye-web` sharing the jobs dir).

## Use

    ./up.sh       # start; first run sets up + seeds everything (~3 min)
    ./down.sh     # stop and WIPE everything (account, peers, history, secrets)

    uv run --project .. --with playwright python shoot.py        # screenshots -> screenshots/{light,dark}/
    uv run --project .. --with playwright python shoot.py dark   # one theme
    uv run --project .. python publish_docs.py                     # curated set -> docs/screenshots/

`publish_docs.py` copies 12 pages × light/dark into `docs/screenshots/`
(pngquant + oxipng, ImageMagick fallback; ~1.8 MB), shown by
`docs/screenshots.md` and the README. Only re-publish when the UI visibly
changed — every run adds to the repository.

After code changes, rebuild only our images:

    DEMO_VERSION=$(cat ../VERSION) DEMO_REVISION=$(git -C .. rev-parse HEAD) \
      docker compose -f compose.yml -f peers.yml up -d --build birdseye birdseye-web

- birdseye-web: http://localhost:58090 (built from this checkout)
- NetBird dashboard: http://netbird.localhost:58080
- Login: `secrets.env` → DEMO_OWNER_EMAIL / DEMO_OWNER_PASSWORD (owner),
  DEMO_PW_<USER> for anna/ben/clara/dan/eve

Needs: Docker Desktop running, `uv`, ports 58080, 58090, 3478/udp free.
Playwright's Chromium: `uv run --with playwright python -m playwright install chromium`.

## How it works

- **One URL everywhere**: `http://netbird.localhost:58080`. macOS resolves
  `*.localhost`; containers get it via `extra_hosts: host-gateway`. Traefik
  listens on 58080 inside and outside, so the URL is the same for both.
- **Owner + API token without clicking**: `netbird-server` runs with
  `NB_SETUP_PAT_ENABLED=true`; `seed.py` calls `POST /api/setup` with
  `create_pat` and stores the token in `secrets.env` (birdseye reads it).
- **birdseye-web callback** `http://localhost:58090/auth/callback` is in
  `config.yaml` → `dashboardRedirectURIs`.
- **Peers** (`peers.yml`, generated by `seed.py`): real `netbirdio/netbird`
  client containers.
  - Servers/router (web-01, web-02, db-01, office-gw) enroll with setup keys.
  - Laptops (anna-mbp, ben-laptop, clara-laptop, clara-desktop, dan-laptop,
    eve-laptop) have no key: their `netbird up` prints a device-code URL,
    `login_users.py` logs in there as the user (Playwright, fresh context per
    user, confirms the code, restarts the client if the code expired). So they
    are user-owned like in prod. User passwords only come back from
    `POST /api/users` at creation — that's why `seed.py` stores them.
- **NetBird defaults removed** (`seed.py` → `remove_defaults`, also in `late`):
  the "Default" All↔All policy, the onboarding network "My First Network"
  with its policies, setup key and the groups "Users"/"Routing Peers".
  Otherwise every matrix cell is green. Keep no All↔All rule in the demo.
- **Drift on purpose** (`seed.py late`): ben-laptop extra in Servers,
  clara-desktop missing Developers → user editor "fix", anomalies.
- **History**: `up.sh` clears it, takes a baseline (`--force`) and runs
  `changes.py` (two rounds, each waits for the forwarder's automatic
  snapshot). Re-run that block for a clean history diff. Never `import
  changes` without the `__main__` guard (it would re-apply the rounds).
- `shoot.py` logs in through the real IdP form (owner), makes one change via
  birdseye-web (SSH on web-02 → audit "birdseye" badge), then shoots 25 pages
  per theme, 1440×900 @2x, de-DE / Europe/Berlin.

## Files

| File | What |
|---|---|
| `compose.yml` | traefik, netbird-server, dashboard, birdseye, birdseye-web |
| `config.yaml.tpl` → `config.yaml` | combined server config (keys generated by up.sh) |
| `dashboard.env` | dashboard OIDC settings |
| `seed.py` | setup, demo data, `peers.yml`; `late` = defaults/direct-peer/drift |
| `login_users.py` | device-code login of user-owned peers |
| `changes.py` | two rounds of config changes for History/Audit |
| `shoot.py` | screenshots |
| `roles_check.py` | walk every page as non-admin users (ben = user, frank = auditor); `--view-unblocked` |
| `publish_docs.py` | curated, compressed screenshots for the docs |
| `secrets.env`, `web.env`, `peers.yml`, `data/` | generated, wiped by down.sh |
